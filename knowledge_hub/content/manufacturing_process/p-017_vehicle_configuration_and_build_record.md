# Vehicle Configuration and Build Record

## Purpose

This Truck-X synthetic knowledge card supports quality_8d, knowledge_assistant for North American day-cab and sleeper-truck manufacturing.

## Approved guidance

The build record should connect VIN, model, cab type, powertrain, axles, options, software, certification market, critical components, process results, repair history, and final release. Configuration mismatches require stop and review.
