# Local and Gemini Execution

## Reliability contract

The local engine is the required processing layer. Gemini is optional. A Gemini failure does not change a successful local result into a workflow failure.

## User-visible status

- **Local:** Result generated by the local deterministic engine. Gemini AI was not used.
- **Fallback:** Result generated successfully by the local deterministic engine. The optional Gemini AI enhancement was unavailable and was not used.
- **Enhanced:** Result generated by the local deterministic engine and enhanced with an optional Gemini AI review. Human validation remains required.

## Workflow states

- `not_requested` — Gemini was disabled or not needed.
- `success` — Gemini enrichment completed.
- `failed` — Gemini was requested but unavailable; local output was preserved.

## Failure scenarios covered

- Missing or invalid API key
- Unsupported or retired model
- Network or corporate proxy interruption
- Timeout or rate limit
- Invalid structured response
- SDK/client error

## Operational behavior

Users can continue editing, reviewing, downloading readable documentation, and downloading JSON whenever the local engine succeeds.
