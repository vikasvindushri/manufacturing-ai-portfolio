# Human-in-the-Loop Governance
- AI output is always a draft or hypothesis.
- Named accountable owner approves disposition and actions.
- Evidence and source references accompany recommendations.
- Overrides and approval timestamps are retained.
- Access follows least privilege; production data is minimized and classified.
- Model/rule changes require validation against a frozen test set.
- Stop-use triggers include unsupported citations, hazardous advice, abnormal override rate or data leakage.
